Earned value indicators

CPI = EV / AC{{'%.3f'|format(evm.cpi) if evm.cpi is not none else 'N/A'}}
SPI = EV / PV{{'%.3f'|format(evm.spi) if evm.spi is not none else 'N/A'}}
Cost variance = EV − AC{{evm.cv|money}}
Schedule variance = EV − PV{{evm.sv|money}}
Planned sum of activity costs{{total_cost|money}}
Approved project budget{{project.approved_budget|money}}

Warnings trigger when CPI or SPI is below 0.95, spending exceeds approval, or forecast completion exceeds the current deadline.

Reporting date & EVM method

PV = Σ (planned cost × time-phased fraction complete as of reporting date). EV = Σ (planned cost × actual work %). AC = Σ actual expense entries. If a denominator is zero, its index is displayed as N/A.
